# Shivang Dubey Portfolio

A responsive, multi-page personal portfolio built with React, Vite, React Router, Framer Motion and Lucide icons. The visual design is image-free and uses a premium dark palette with electric-blue accents.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production build

Run `npm run build`. The production files are generated in `dist/`.

## Deploy to Vercel

1. Create a GitHub repository and upload this project.
2. Import the repository into Vercel.
3. Vercel should detect Vite automatically.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy. Vercel will provide a free `vercel.app` URL.

## Notes

- No photographs, stock images, illustrations or gallery are included.
- No CV section or database is included.
- Project extensions are labelled as planned, not completed.
- Achievement counters are represented as factual highlight cards rather than invented numerical totals.
